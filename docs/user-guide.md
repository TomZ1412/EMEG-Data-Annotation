# EEG 数据标注平台用户说明

版本：v1.0  
适用对象：数据标注员  
更新时间：2026-05-18

## 1. 平台用途

本平台用于查看 EEG 数据的 PSD 和波形，并对异常通道进行坏道标注。标注结果会保存到服务器，供后续数据清洗和分析使用。

平台支持：

- 查看待标注数据列表
- 查看 PSD 视图
- 查看波形视图
- 标记或取消标记坏道
- 按时间子图分别标注坏道
- 标记整条数据为弃用
- 多人协作时避免同时标注同一条数据

说明：平台整体界面截图，标出左侧文件树、中间可视化区域、右侧标注面板。

## 2. 首次进入

打开网页后，系统会提示输入用户名。用户名用于记录标注者身份，并用于多人协作时显示文件占用状态。

请输入一个容易识别的用户名，例如：

```text
zhangsan
user01
```

## 3. 页面区域说明

页面主要分为三个区域：

| 区域 | 功能 |
|---|---|
| 左侧文件树 | 选择要标注的数据 |
| 中间可视化区域 | 查看 PSD 和波形 |
| 右侧标注面板 | 查看当前子图、坏道列表、提交标注 |

中间可视化区域上方会显示当前数据的相对路径，便于确认正在标注哪条数据。

图片建议：`images/03-layout.png`  
说明：页面结构截图，分别标注三个主要区域。

## 4. 文件状态说明

左侧文件树中，不同状态表示不同含义：

| 状态 | 含义 |
|---|---|
| 未标注 | 当前数据还没有提交标注 |
| 已标注 | 当前数据已经完成标注 |
| 占用中 | 当前数据正在被某个用户标注 |
| 弃用数据集 | 该数据集被标记为不可用 |

如果文件显示为占用中，说明其他用户正在标注该文件，请选择其他文件。

图片建议：`images/04-file-tree-status.png`  
说明：文件树中不同状态的示例截图。

## 5. 推荐标注流程

建议按以下步骤完成一条数据的标注：

1. 在左侧文件树选择一个未标注文件。
2. 先查看 PSD 视图，快速发现异常通道。
3. 切换到波形视图，逐个时间段确认异常通道。
4. 对坏道进行标记。
5. 如果整条数据质量很差，勾选“弃用该数据”。
6. 点击“提交标注”。
7. 系统会保存标注，并跳转到下一条未标注数据。

图片建议：`images/05-workflow.png`  
说明：用流程图展示推荐标注流程。

## 6. PSD 视图使用

PSD 视图用于查看各通道的功率谱密度。每条曲线对应一个通道。

可用操作：

| 操作 | 效果 |
|---|---|
| 鼠标悬停在曲线上 | 高亮对应通道 |
| 鼠标悬停在右侧通道名上 | 高亮对应 PSD 曲线 |
| 点击曲线 | 标记或取消标记该通道为坏道 |
| 点击右侧通道名 | 标记或取消标记该通道为坏道 |
| 框选 PSD 区域 | 批量标记或取消标记框内通道 |

已标记为坏道的通道会显示为红色。

图片建议：

- `images/06-psd-view.png`：PSD 视图整体截图
- `images/07-psd-hover.png`：PSD 通道高亮截图
- `images/08-psd-select.png`：PSD 框选标注截图
- `images/09-psd-bad-channel.png`：坏道标红截图

## 7. 波形视图使用

波形视图用于查看当前时间段内的多通道 EEG 波形。

可用操作：

| 操作 | 效果 |
|---|---|
| 点击通道波形 | 标记或取消标记坏道 |
| 鼠标悬停在通道上 | 高亮对应通道 |
| 调整 Scale | 改变波形显示幅度 |
| 点击底部进度条 | 跳转到指定时间子图 |
| 输入子图编号 | 跳转到指定子图 |
| 点击 Marked sub-blocks 中的编号 | 跳转到已经标记坏道的子图 |

每个子图的坏道标注是独立的。也就是说，第 1 个子图标记的坏道不会自动应用到第 2 个子图。

- `images/12-sub-block-slider.png`：底部子图切换区域截图

## 8. 坏道标注说明

坏道可以通过 PSD 视图或波形视图标注。

标注后：

- 当前子图的坏道会显示在右侧“当前坏道”区域。
- 有坏道的子图会显示在波形视图上方的 `Marked sub-blocks` 区域。
- 点击 `Marked sub-blocks` 中的编号，可以快速回到对应子图检查。

如果误标了通道，再次点击该通道即可取消标注。

图片建议：`images/14-bad-channel-panel.png`  
说明：右侧当前坏道列表截图。

## 9. 弃用整条数据

如果整条数据质量很差，例如大部分通道异常、信号严重缺失、噪声极强，可以勾选右侧面板中的“弃用该数据”。

勾选后仍需要点击“提交标注”，弃用状态才会保存。

图片建议：`images/15-discard-data.png`  
说明：弃用数据勾选框截图。

## 10. 提交标注

完成检查后，点击右侧“提交标注”按钮。

提交后系统会：

- 保存当前文件所有子图的坏道标注
- 保存是否弃用该数据
- 释放当前文件占用状态
- 跳转到下一条未标注数据

图片建议：`images/16-submit.png`  
说明：提交标注按钮和成功提示截图。

## 11. 多人协作注意事项

多人同时使用平台时，请注意：

- 不要长时间打开一个文件但不进行标注。
- 如果某个文件显示为其他用户占用，请选择其他文件。
- 完成标注后请及时提交。
- 如果页面异常关闭，文件可能需要等待一段时间后自动释放。

图片建议：`images/17-busy-file.png`  
说明：文件 busy 或占用状态截图。

## 12. 常见问题

### 12.1 打开网页后没有文件列表

可能原因：

- 后端服务暂时不可用
- 数据目录尚未刷新
- 网络连接异常

处理方式：

- 点击页面上的“刷新文件”
- 刷新浏览器页面
- 联系管理员检查后端服务

### 12.2 点击文件后一直 Loading

可能原因：

- 数据文件正在加载
- 网络较慢
- 数据文件损坏或缺失

处理方式：

- 等待几秒
- 点击“刷新数据”
- 切换到其他文件再切回
- 如果仍然无法显示，联系管理员

### 12.3 PSD 无法框选标注

请确认当前 PSD 工具栏处于框选或套索选择模式。如果切换到了缩放或平移模式，请重新选择框选工具。

### 12.4 标错了坏道怎么办

再次点击同一个通道即可取消标注。

### 12.5 提交后发现标错了怎么办

可以重新打开该文件，修改标注后再次提交。新的提交会覆盖旧标注。

## 13. 标注质量建议

标注时建议：

- 先看 PSD，快速定位明显异常通道。
- 再看波形，确认异常是否持续存在。
- 不确定的通道可以结合多个子图判断。
- 对整条数据质量极差的情况，优先考虑弃用该数据。
- 每次提交前检查右侧坏道列表和弃用状态。
